# Ceaute MVP — design handoff

Design references and implementation notes for the Ceaute MVP UI, prepared for
implementation with Claude Code on a branch of `horridharry/ceaute`.

**Start with `README.md`.** Then read in order:

1. `01-foundations.md` — colour, type, spacing, radius, motion
2. `02-components.md` — every component with its states
3. `03-screens.md` — route by route
4. `04-divergences-and-gaps.md` — design vs. current code
5. `05-build-order.md` — sequence and review checklist
6. `06-copy-deck.md` — every user-facing string

`designs/` holds the HTML prototypes. Open them straight in a browser — no build step.
`designs/github.md` is the sync record tying these designs to the repo, including the
product rules read out of the code.

The photographs in `designs/uploads/` are sample content for the mockups only. Do not
commit them as fixtures.
