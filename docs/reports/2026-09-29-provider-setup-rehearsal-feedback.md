# Provider setup rehearsal: owner feedback, 29 September 2026

Dated snapshot. After `ceaute-dev` and the Stripe Test sandbox were wiped, the
owner set up a new test provider on Preview from sign-up to publication, as a
rehearsal of the first pilot provider's setup. These are the owner's comments,
in their order. None is built yet; "deferred" means the owner said it can wait.

1. Durations: customers should not have to add up treatment and add-on times
   in their head. Deferred.
2. Ceaute category: offer only the categories that fit the main category
   chosen. Deferred.
3. Treatment groups: create a new group from inside the new-treatment form and
   assign it to that treatment straight away.
4. A quick way for an admin to fill in forms.
5. Add-on fields start with "0" already typed in; they should start empty.
6. Deleting a photo should be quicker. Deferred.
7. Research address autofill for locations.
8. When the last setup-guide item is done, lead the provider to publish their
   page; otherwise they do not know where to go next.
9. Make publishing a celebratory moment, without being cringe.
